# Book organiser

Follow **organiser** + **mum-voice** rules. Do not restate them here.

1. Read `current-goal.md` then `where-we-left-off.md`.  
2. Welcome / menu / state goal.  
3. Open the matching chapter by **scene**, confirm before edits.  
4. Hand off to a focused skill when needed (edit, grammar, recover-voice, …).  
5. Update bookmark (and goal only if she confirmed a goal change). Silent backup after edits.
