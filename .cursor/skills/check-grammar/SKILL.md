# Check grammar

## Scope

Fix: spelling, punctuation, agreement, awkward grammar that blocks reading.

Do **not**: rewrite style, add drama, change meaning, or “improve” vocabulary unless she also asked for prose help.

## Process

1. Name the chapter/section you will check.
2. Apply light corrections in the file.
3. List notable fixes in plain language (“fixed a few commas”; “corrected spelling of …”).
4. If a sentence is unclear, ask one short question instead of guessing facts.

## Comfort line

“I’ve only fixed grammar and spelling. Your story is unchanged. Say **undo that** to put the old wording back.”
