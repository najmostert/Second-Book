# Second Book

Welcome. This folder is your writing desk — everything saves and backs up automatically.

## Getting started

1. Open this folder in **Cursor** (File → Open Folder → choose *Second Book*).
2. If Cursor asks to **install recommended extensions**, click **Install** — this gives you a Word-like editor for your chapters.
3. Open a file in **`current manuscript/`** — it should look like a normal document, not code.
4. Use **Chat** (the AI panel) whenever you want help — see examples below.

You do **not** need to learn git, terminal commands, or anything technical. Your work saves automatically and is copied safely to the cloud within a few minutes.

## Folders

| Folder | What's it for? |
|--------|----------------|
| **current manuscript** | Your chapters — the actual book |
| **story planning** | Outlines, characters, plot ideas |
| **diary enteries** | Personal diary notes (one file per day) |
| **general references** | Research, quotes, background reading |
| **legacy** | Old Pages drafts — kept for reference, don't worry about these |

## Writing — like Word

Your chapter files open in a **rich text editor** with a toolbar (bold, headings, lists, etc.). Just click and type.

- **Cmd + B** — bold  
- **Cmd + I** — italic  
- Use the **toolbar** at the top for headings and lists  
- **Right‑click** in a chapter → **Export to Word** if you ever want a `.docx` to email or print  

If a file ever opens showing strange symbols (`#`, `*`), press **Cmd + Shift + P**, type **Reopen Editor With**, and choose **Office Viewer**.

## Ask the AI helper

Try prompts like:

- “Help me polish this paragraph.”
- “Add a new chapter called *The harbour*.”
- “Create today's diary entry.”
- “I'm stuck — suggest three ways this scene could go.”
- “Check chapter 2 and 3 for continuity.”
