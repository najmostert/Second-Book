# Second Book

Welcome. This folder is your writing desk — everything saves and backs up automatically.

## Getting started

1. Open this folder in **Cursor** (File → Open Folder → choose *Second Book*).
2. Open a file in **`current manuscript/`** and start writing.
3. Use **Chat** (the AI panel) whenever you want help — see examples below.

You do **not** need to learn git, terminal commands, or anything technical. When you save a file, your work is copied safely to the cloud within a few minutes.

## Folders

| Folder | What's it for? |
|--------|----------------|
| **current manuscript** | Your chapters — the actual book |
| **story planning** | Outlines, characters, plot ideas |
| **diary enteries** | Personal diary notes (one file per day) |
| **general references** | Research, quotes, background reading |
| **legacy** | Old Pages drafts — kept for reference, don't worry about these |

## Ask the AI helper

Try prompts like:

- “Help me polish this paragraph.”
- “Add a new chapter called *The harbour*.”
- “Create today's diary entry.”
- “I'm stuck — suggest three ways this scene could go.”
- “Check chapter 2 and 3 for continuity.”

## Saving

- **Cmd + S** saves the file on your Mac.
- Backup to GitHub happens automatically — you never need to think about it.
