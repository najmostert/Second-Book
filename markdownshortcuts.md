# Markdown shortcuts for writers

Type these in your `.md` files. Cursor may also format selected text if you use the editor toolbar.

| You type | You get |
|----------|---------|
| `# Title` | Large chapter title |
| `## Section` | Section heading |
| `*text*` | *italic* |
| `**text**` | **bold** |
| `"dialogue"` | Dialogue (quotes as you normally would) |
| `- item` | Bullet list |
| `1. item` | Numbered list |
| `---` | Horizontal line between scenes |
| `> quote` | Block quote (for letters, excerpts) |

## Examples

```markdown
# Chapter Three

The morning was still.

"I don't know," she said.

---

## Later that evening

- She walked to the harbour.
- The lights were out.
```

## Preview (optional)

**Cmd + Shift + V** — open Markdown preview for the current file (shortcut may vary; use View → Open Preview if needed).
